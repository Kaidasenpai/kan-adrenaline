# Adrenaline Tasks direction

Direction: high-end-visual-design, soft structuralism adapted to an editorial production workspace.

The user rejected the first generic square/check logo and requested a full professional UI/UX redesign. The original stacked ADRENA / LINE logotype and offset-square geometry now lead the identity. Generated high-fidelity references for Boards and sign-in lead implementation, with real live data and workflows preserved. Product usability takes precedence over marketing-site skill prescriptions such as giant pill buttons, scroll reveals, and nested decorative boxes.

- Brand lime: #B4D234; hover: #AAC731; muted: #90A829.
- Ink on lime: #171A12; accessible accent on light surfaces: #536312.
- Light canvas #F5F5F2, white working panels, ink #171A15. Dark canvas #151713, working panels #20241F, text #F4F4EF. Preserve semantic task colors.
- Keep Plus Jakarta Sans for legible UI text. The brand lockup uses geometric uppercase typography; do not extract the PDF's proprietary demo fonts.
- Preserve the original stacked wordmark geometry. TASKS is a small aligned descriptor; no literal checkmark logo. Use the original offset-square symbol for compact icons.
- Rebuild board tiles with left-aligned titles, real column names, visibility and an opening affordance. Add meaningful page hierarchy, navigation groups, controlled spacing, refined columns/cards and settings/members presentation.
- Accent primary actions, selection, navigation, and keyboard focus. Use brief feedback transitions only, support reduced motion, avoid scroll reveals on working views, gradients, and saturated board backgrounds.
- Logo assets stay local and static. No image optimization service, storage subscription, paid Workers binding, or hosting plan change.
- Preserve source attribution, AGPL license, account access, workflows, and existing workspace data.

Deliverables: (1) professional Tasks sub-brand with the original logotype; (2) high-fidelity references and a implemented full app redesign, verified on desktop/mobile and both themes and deployed on existing Free hosting.
